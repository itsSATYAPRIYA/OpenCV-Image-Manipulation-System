# OpenCV Image Manipulation System

A Python-based image manipulation program built using OpenCV.

## Features

1. Resize Image
2. Crop Image
3. Rotate Image
4. Flip Image
5. Draw Line
6. Draw Rectangle
7. Draw Circle
8. Add Text to Image

## Technologies Used

- Python
- OpenCV

## How to Run

Install OpenCV:

pip install opencv-python

Then run:

python image_manipulation.py
